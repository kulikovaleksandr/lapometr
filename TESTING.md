# Тестирование Лапометра

Проект использует два уровня тестирования:

## Unit-тесты (Vitest)

Тестирование доменной логики без UI.

### Запуск

```bash
# Запустить все тесты в watch-режиме
npm run test

# Запустить тесты один раз
npm run test -- --run

# Запустить с UI
npm run test:ui

# Запустить с покрытием кода
npm run test:coverage
```

### Структура тестов

- `src/test/domain.test.ts` — тесты доменной логики:
  - `limitsFor` — проверка лимитов активностей
  - `streakDays` — расчёт серий дней
  - `computeDue` — вычисление просроченных активностей
  - `nextOccurrence` — расчёт следующего наступления вет-событий (включая 31-е число)

### Покрытие

Тесты покрывают:
- Граничные случаи (31-е число в месяце с 30 днями)
- Пустые данные
- Превышение лимитов
- Расчёт серий с пропусками
- Просроченные и предстоящие активности

## E2E-тесты (Playwright)

Тестирование полных пользовательских сценариев в реальном браузере.

### Установка

```bash
# Установить браузеры
npx playwright install
```

### Запуск

```bash
# Запустить все e2e тесты
npm run test:e2e

# Запустить с UI
npm run test:e2e:ui

# Запустить конкретный тест
npx playwright test full-scenario.spec.ts

# Запустить в конкретном браузере
npx playwright test --project=chromium
```

### Структура тестов

- `e2e/full-scenario.spec.ts` — полный сценарий:
  1. Регистрация нового пользователя
  2. Создание профиля и питомца
  3. Отметка активности
  4. Проверка журнала
  5. Проверка дуэли
  6. Проверка статистики
  7. Проверка настроек

- Демо-режим:
  1. Вход в демо-режим
  2. Проверка загрузки демо-данных
  3. Проверка нескольких питомцев
  4. Проверка журнала с записями
  5. Проверка дуэли с двумя хозяевами

### Конфигурация

`playwright.config.ts`:
- Base URL: `http://localhost:5173`
- Браузеры: Chromium
- Dev-сервер запускается автоматически
- Трейсы сохраняются при повторных попытках

## CI/CD

Тесты интегрированы в GitHub Actions:

```yaml
# .github/workflows/test.yml
name: Tests
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run test -- --run
      - run: npx playwright install --with-deps chromium
      - run: npm run test:e2e
```

## Добавление новых тестов

### Unit-тесты

1. Создайте файл `src/test/<module>.test.ts`
2. Импортируйте функции из `src/lib/`
3. Используйте `describe`, `it`, `expect` из Vitest
4. Покрывайте граничные случаи

### E2E-тесты

1. Создайте файл `e2e/<scenario>.spec.ts`
2. Используйте `test`, `expect` из Playwright
3. Тестируйте полные пользовательские сценарии
4. Используйте `page.getByRole()`, `page.getByText()` для поиска элементов

## Метрики качества

- **Покрытие кода**: цель >80% для доменной логики
- **Время выполнения**: unit-тесты <10с, e2e <60с
- **Стабильность**: 0 flaky тестов
- **Скорость**: параллельное выполнение тестов

## Известные ограничения

- E2E-тесты требуют запущенный dev-сервер
- Некоторые тесты зависят от времени (серии, напоминания)
- Демо-данные генерируются случайно (используется seed)
