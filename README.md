# 🐾 Лапометр

Веб-приложение для учёта заботы о домашних питомцах с геймификацией и соревновательным элементом.

## ✨ Основные возможности

### 📊 Учёт активностей
- Журнал всех действий по уходу за питомцем
- Система лапок (баллов) за каждую активность
- Отслеживание прогресса и статистики

### 👥 Мультипользовательность
- Несколько хозяев для одного питомца
- Система ролей (владелец/помощник)
- Возможность отмечать активности "от имени" другого хозяина

### 🏆 Дуэль хозяев
- Соревнование между хозяевами по количеству лапок
- Периоды: сегодня, неделя, месяц, сезон, всё время
- История победителей и чемпион года

### 📅 Сезонная механика
- **Автоматическое обнуление лапок** каждый месяц
- Настройка дня обнуления (по умолчанию 1-е число)
- Чип с информацией о текущем сезоне и днях до конца
- «Кубок» с историей победителей по месяцам

#### 🎯 Краевые случаи (реализовано)

**Питомец создан в середине месяца**
Если питомец создан не в начале месяца, сезон начинается с даты создания питомца, а не с 1-го числа месяца. Это обеспечивает справедливый учёт с самого начала.

*Пример:* Питомец создан 15-го июня → сезон длится с 15-го июня по 30-е июня.

**Хозяин вышел из питомца посреди сезона**
Если хозяин покидает питомца в середине сезона, его результаты за этот сезон сохраняются, но с пометкой о бывших хозяевах. Это обеспечивает прозрачность истории.

*Пример:* Хозяин А участвовал в сезоне, затем покинул питомца. При закрытии месяца результат сохраняется с пометкой: "Результат включает данные бывших хозяев: 1 чел."

## 🛠 Технологический стек

- **Frontend:** React 18, TypeScript, Vite
- **Стили:** Tailwind CSS v4
- **База данных:** localStorage (локально) + Supabase (облако)
- **Авторизация:** Supabase Auth (Google OAuth, email)

- **Storage:** Supabase Storage для фото
- **Мониторинг:** Sentry, Plausible

## 📦 Установка и запуск

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

### Переменные окружения

Создайте файл `.env` на основе `.env.example`:

```bash
# Supabase (опционально, для облачного режима)
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key

# Мониторинг (опционально)
VITE_SENTRY_DSN=your-sentry-dsn
VITE_PLAUSIBLE_DOMAIN=your-domain.com

# Web Push (опционально)
VITE_VAPID_PUBLIC_KEY=your-vapid-public-key
```

### Подключение облака Supabase

Приложение поддерживает два варианта подключения облака:

#### Вариант A: Через переменные окружения (для продакшена)

Рекомендуется для продакшен-развёртывания. Облако настраивается один раз при сборке.

1. Создайте проект на [supabase.com](https://supabase.com)
2. Выполните миграции из `supabase/migrations/` в SQL Editor
3. Настройте переменные окружения:
   ```bash
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```
4. Пересоберите приложение: `npm run build`
5. В настройках приложения появится упрощённая форма входа (без полей URL/key)

**Преимущества:**
- Безопасность: ключи не хранятся в браузере пользователя
- Простота: пользователям не нужно настраивать подключение
- Централизация: все пользователи работают с одним проектом Supabase

#### Вариант B: Ручное подключение (для разработки)

Подходит для локальной разработки и тестирования. Каждый пользователь может подключить свой проект Supabase.

1. Создайте проект на [supabase.com](https://supabase.com)
2. Выполните миграции из `supabase/migrations/` в SQL Editor
3. В настройках приложения откройте раздел "Облако и синхронизация"
4. Введите Project URL и Anon key из Settings → API
5. Нажмите "Проверить и подключить"
6. Войдите в аккаунт или зарегистрируйтесь

**Преимущества:**
- Гибкость: можно тестировать с разными проектами Supabase
- Изоляция: данные разных пользователей не пересекаются
- Разработка: удобно для тестирования миграций и настроек

**Примечание:** Если переменные окружения заданы, ручное подключение недоступно.

## 🗄 Структура базы данных

### Локальное хранилище (localStorage)
- `lapometr.db` - основная база данных
- `lapometr.session` - сессия пользователя
- `lapometr.theme` - выбранная тема

### Облачное хранилище (Supabase)
- `users` - пользователи
- `pets` - питомцы
- `pet_owners` - связь питомцев и хозяев
- `activities` - типы активностей
- `logs` - журнал активностей
- `chat_messages` - чат хозяев
- `vet_events` - ветеринарные события
- `weights` - записи веса
- `expenses` - расходы
- `push_subscriptions` - подписки на push-уведомления
- `sync_snapshots` - снапшоты для синхронизации

## 🔒 Безопасность

- Пароли хэшируются (djb2 для локального режима, bcrypt для облачного)
- RLS-политики в Supabase для защиты данных
- Анти-чит система для лимитов активностей
- Гигиена снапшотов (пароли и email не попадают в облако)
