- [x] **Хозяин вышел из питомца посреди сезона**: сохраняем результат с пометкой о бывших хозяевах
  - В `finalizeMonth()` проверяем, есть ли пользователи в pawsByUser, которые больше не в ownerIds
  - Добавляем поле `note` в MonthlyResult с информацией о бывших хозяевах
  - Результат сохраняется, но с пометкой для прозрачности
  
- [x] **Питомец создан в середине месяца**: сезон начинается с даты создания
  - В `getSeasonStart()` сравниваем дату создания питомца с началом сезона
  - Если питомец создан после начала сезона, сезон начинается с `pet.createdAt`
  - В `getSeasonEnd()` учитываем этот случай для корректного расчёта конца сезона
  - Логи до создания питомца автоматически исключаются из сезонной статистики

#### Реализация краевых случаев:

**1. Питомец создан в середине месяца:**
```typescript
// В getSeasonStart():
const petCreatedAt = new Date(pet.createdAt);
if (petCreatedAt > seasonStart) {
  return pet.createdAt; // Сезон начинается с даты создания
}
```

**2. Хозяин вышел из питомца:**
```typescript
// В finalizeMonth():
const currentOwnerIds = new Set(pet.ownerIds);
const previousOwners = Object.keys(pawsByUser).filter(id => !currentOwnerIds.has(id));

if (previousOwners.length > 0) {
  note = `Результат включает данные бывших хозяев: ${previousOwners.length} чел.`;
}
```
